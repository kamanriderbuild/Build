连接电脑

APK 需要连接电脑上的验车服务。请保证手机与电脑同一 Wi‑Fi，电脑已运行 npm start。

安装到手机主屏幕

网页版不能像应用商店那样直接装 APK。正确做法是「添加到主屏幕」，图标和用法跟 App 一样。

若按钮无效，请用下方手动步骤。

iPhone / iPad（必须用 Safari）

  1. 用 Safari 打开本页面（不要用微信内置浏览器）
  2. 点底部分享按钮 □↑
  3. 下滑找到并点 添加到主屏幕
  4. 点右上角 添加

安卓手机（推荐 Chrome）

  1. 用 Chrome 打开本页面（不要用微信）
  2. 点右上角菜单 ⋮
  3. 选择 添加到主屏幕 或 安装应用
  4. 确认添加后，桌面会出现「车子验车」图标

在电脑上给手机安装

  1. 保证手机和电脑连同一个 Wi‑Fi
  2. 手机浏览器打开下面的地址，或扫描二维码
  3. 打开后再按手机系统步骤「添加到主屏幕」

用手机扫码打开

装好后从桌面图标进入即可使用；电脑上的 npm start 服务需要保持运行，照片才会保存到电脑文件夹。
